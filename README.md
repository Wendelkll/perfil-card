# 📄 Perfil de Usuario (Card)

## 📌 Descripción
Este proyecto es una tarjeta de perfil simple hecha con **HTML y CSS**. Muestra la información básica de un usuario, incluyendo su foto, nombre, edad, ubicación y estadísticas (seguidores, likes y fotos).

## 🚀 Tecnologías usadas
- HTML5  
- CSS3  
- Reset CSS  
- Variables CSS  

## 📂 Estructura
- `index.html` → estructura principal  
- `css/` → estilos (reset, variables, diseño)  
- `src/images/` → imágenes del perfil  

## 🎯 Funcionalidad
- Diseño de tarjeta centrada  
- Información del usuario  
- Estadísticas organizadas en lista  
- Estilo limpio y moderno
